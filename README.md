# AbleNova

## AI-Powered Accessible & Adaptive Learning Platform

AbleNova is an AI-powered personalized learning platform designed specifically for children with disabilities.

The platform aims to make digital education more accessible, personalized, interactive, and effective by adapting learning content according to individual student needs and performance.

## Core Features

* Accessible learning interface
* Personalized learning paths
* Adaptive difficulty
* Interactive quizzes
* AI-powered explanations
* RAG-based educational assistance
* Student progress tracking
* Learning mastery estimation
* Teacher dashboard
* Caregiver dashboard
* Offline-first learning
* Low-bandwidth support
* Accessibility customization

### Frontend

### Backend

FastAPI + Python + PostgreSQL + Supabase

### AI
